# RAG 三组对照实验报告

## 实验设计
- Baseline-A：纯 BM25 关键词检索 + 直接生成。
- Baseline-B：朴素 RAG，使用固定 512 字符重分块 + 单路向量检索。
- System：复用当前系统的结构感知分块、多通道混合检索、重排和 CRAG 评估。

## 数据集
- 数据集名称：ai-school-counselor-rag-eval
- 样本总数：240
- 可回答样本：216
- 无答案样本：24

## 典型问题归因

### Baseline-A
- 问题：团体辅导中‘我的资源盾牌’环节要求参与者在盾牌上记录哪8个问题的答案？
  结论：应答但未回答，检索失败；问题类型：retrieval
- 问题：新生校园卡制作发放由哪个部门统筹？
  结论：回答错误且编造部门；问题类型：generation
- 问题：马骏涛申请临时困难补助的理由中，提到其家庭面临哪些具体经济压力？
  结论：检索失败导致完全无法作答；问题类型：retrieval

### Baseline-B
- 问题：北航在研究生国际交流方面提供了哪些经费支持项目？请列举至少三项。
  结论：回答完全虚构，证据中无任何相关内容；问题类型：generation
- 问题：马骏涛申请临时困难补助的理由中，提到其家庭面临哪些具体经济压力？
  结论：检索失败，未找到相关证据；问题类型：retrieval
- 问题：电子信息工程学院开设的新生研讨课中，哪些课程的学分是1、学时是16？
  结论：回答严重错误，漏答全部14门课且虚构课程；问题类型：generation

### System
- 问题：‘我的资源盾牌’活动结束后，带领者强调这些资源的核心作用是什么？
  结论：应答但无检索证据导致拒答；问题类型：retrieval
- 问题：自动化科学与电气工程学院开设的新生研讨课中，哪门课的学分是1.5？
  结论：回答编造课程，证据中无该课信息；问题类型：generation
- 问题：《杭州市北京航空航天大学国际创新研究院临时公寓管理办法（试行）》由哪个部门负责解释？
  结论：回答错误且编造解释部门；问题类型：generation

## 论文撰写建议
- 正式论文建议优先使用 manual_eval_dataset.json，经人工复核后再跑最终分数。
- 若 Baseline-B 在 HitRate 提升但 Faithfulness 下降，可据此论证“仅增大召回不足以提升端到端效果”。
- 若 System 的 Hallucination 更低、Fallback 更稳，可突出 CRAG 和混合检索的贡献。
